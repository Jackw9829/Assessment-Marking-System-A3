
# Assessment & Marking System

## Project Description
The Assessment & Marking System is a web-based application developed to help lecturers manage student assessments, calculate marks, and generate reports efficiently. 

The system allows lecturers to:
- Create assessments
- Enter and update student marks
- Calculate total scores and grades
- Generate reports
- Manage student records
- Upload learning Material

Students can:
- View their assessment results
- Check grades and feedback
- Download learning material
- Submit assignment

## Objectives
- Simplify the assessment marking process
- Reduce manual calculation errors
- Improve efficiency in managing student results
- Provide a centralized platform for assessment records

## Features
- User Authentication (Admin, Lecturer, Student)
- Assessment Creation
- Marks Calculation
- Grade Generation
- Student Result Management
- Dashboard Overview
- Report Generation


## System Modules

### Admin
- Manage users
- Manage courses
- View reports

### Lecturer
- Create assessments
- Enter marks
- Generate grades
- Upload Learning Material

### Student
- View marks
- View feedback
- Download learning material
- Submit assignment
